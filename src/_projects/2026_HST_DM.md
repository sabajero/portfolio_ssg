## *

The concept behind this visual identity was spores and bugs, I was inspired by the microscopic world and wanted to translate that visually into the final blurry ethereal composition. The circular shapes is a digital painting made with custom brushes in Affinity.

Printing: HfK Bremen, Germany

Fonts: Modified Instrument Serif - OffBit trial - Arial

Web Development: Jekyll - html - css - js -> Made with help from Antigravity (Gemini 3.1 Pro)
